信封加密上线后，把一份密文的头部换到另一份密文上，居然也能正常解开：数据密钥必须与主密钥版本绑定，不能只由主密钥决定；附加认证数据必须包含版本与请求方；头部的每个字段都必须参与认证；同一数据密钥不得跨租户复用；解封时必须校验头部声明的版本仍然可用；所有解封失败必须抛出同一种错误类型，不得暴露失败发生在哪一步；批量加解时每一条必须独立处理。不变量：同一明文重复封装得到的结果不同，但都能解回原文；任何头部字段被改动都会导致解封失败。
